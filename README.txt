台股條件選股器 使用說明
========================

【怎麼打開（Windows）】
1. 雙擊 start.bat
   會跳出一個視窗，並自動用瀏覽器打開選股器（網址是 http://localhost:8765）。
2. 使用期間不要關掉那個視窗；用完直接關掉它就好。

如果被「智慧型應用程式控制」擋下：先刪掉解壓出來的資料夾，
對 zip 檔按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再重新解壓縮。

不要直接雙擊 index.html：那樣瀏覽器會擋掉對交易所的連線，只會看到 36 檔示範資料。
（若你是用 CORS Unblock 擴充功能開 index.html，記得用完把擴充功能關掉。）

【技術條件直接篩選】
第一次打開時，選股器會在背景抓兩個交易所近 130 個交易日的「全市場每日收盤行情」，
約需 5 分鐘（左側技術條件下方會顯示進度），期間可以照常使用其他功能。
建好後存在瀏覽器裡，之後每次打開只補新的交易日，幾秒就好；
點「底底高＋破前高」等技術條件會立刻篩出全部符合的股票。
資料怪怪的時候，可以按頁面最下方「重建歷史資料」重新抓。

【每日／盤中即時行情】
- 收盤後：交易所公布當天收盤行情（約下午 2:30 之後）時，選股器會自動抓進來，
  表格的股價、漲跌、成交量會變成今天的收盤，右上角顯示「收盤 日期」。
  頁面開著的話每 30 分鐘檢查一次，也可以按「重新載入」。
- 盤中：勾選右上角「盤中即時」（預設開啟），交易時間內每 3 分鐘更新全部股票的股價
  （證交所即時報價系統，約延遲數秒），右上角顯示「即時 時間」。
- 本益比、殖利率、淨值比會依最新股價換算（EPS、股利、淨值用交易所最近一次公布的數字）。
- 盤中的技術條件會把今天還沒收盤的走勢當成一根 K 棒，收盤前結果可能改變；
  技術訊號的「提醒」則只用收盤資料判斷，避免盤中假訊號。

【自選股與買賣提醒】
- 在股票列表點 ☆ 加入自選股；上方「自選股」分頁可看持有張數、成本、損益與提醒狀態。
- 在個股頁可以設定提醒：股價 ≥ / ≤ 某價位、獲利或虧損達某個 %、出現某個技術訊號。
- 盤中（09:00–13:30）每分鐘抓一次證交所即時報價檢查價格條件；技術訊號在收盤資料更新後檢查。
- 條件成立時會跳出 Windows 桌面通知、提示音和頁面右下角提醒，並記錄在右上角的鈴鐺裡。
  每個提醒觸發一次後會變成「已觸發」，要再監控請按「重新啟用」。
- 網頁必須開著（可以縮到最小）才收得到提醒。第一次請點右上角鈴鐺 →「開啟桌面通知」。
- 交易紀錄可以按「編輯」直接修改。

【資料只存在這台電腦】
自選股、提醒、交易紀錄存在瀏覽器裡（這台電腦、這個瀏覽器、這個網址）。
換電腦或換瀏覽器前，請用頁面最下方「匯出備份」，到新的地方再「匯入備份」。

【Mac 或想用 Python】
在這個資料夾執行  python3 server.py  ，效果相同。

【自動更新】
用 start.bat 開啟時，選股器每天會檢查一次 GitHub 上有沒有新版本；
有的話頁面上方會出現提示和更新內容，按「立即更新」就會下載新檔案並重新載入。
也可以按頁面最下方的「檢查更新」。資料（自選股、提醒、交易紀錄、歷史行情）不受影響。
如果提示說「也更新了伺服器程式」，請關掉 start.bat 的視窗再重新雙擊 start.bat。
更新來源設定在 update.json（GitHub 的 帳號/repository 名稱），一般不需要改。

【檔案說明】
index.html  網頁
style.css   樣式
app.js      程式（資料串接、篩選、技術指標、圖表、自選股與提醒）
server.ps1  本機伺服器（Windows PowerShell 版）
server.py   本機伺服器（Python 版）
start.bat   一鍵啟動
update.json 自動更新來源設定
version.json 目前版本與更新內容

【如果抓不到資料】
按頁面最下方「連線診斷」，等它跑完（約 1 分鐘）按「複製結果」，貼給 Claude。
伺服器視窗裡「[轉接失敗]」開頭的訊息也可以截圖。
上櫃 OpenAPI 讀不到時，選股器會自動改用櫃買中心網站的每日行情（這時上櫃股票沒有 EPS 和產業別）。
